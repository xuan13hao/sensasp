MCP Server

SenSASP ships as a Model Context Protocol server. Install it once, then ask Claude about any of the 1,250 genes in plain English.

PyPI
pip install sensasp-mcp
Zero-install
uvx sensasp-mcp
pypi.org/project/sensasp-mcp ↗

Connect to Claude Desktop

After pip install sensasp-mcp, add this to your Claude Desktop config (~/.config/claude/claude_desktop_config.json on Linux, ~/Library/Application Support/Claude/claude_desktop_config.json on Mac), then restart Claude Desktop. 

{
  "mcpServers": {
    "sensasp": {
      "command": "python3",
      "args": ["-m", "sensasp_mcp.server"]
    }
  }
}

Available Tools

Tool Description
search_genes Free-text + filter search by source, conservation, expression, STRING degree
get_gene Full record for one gene: conservation, GTEx top tissues, STRING partners with scores
get_database_stats Gene count, annotation coverage percentages, build metadata
list_sources The 4 seed databases with gene counts, descriptions, and URLs
get_top_hub_genes Top-N genes by STRING intra-set interaction degree
get_multi_source_genes All 173 genes confirmed by ≥2 seed sources

Remote / Self-hosted

Deploy on any server so users connect without a local install: 

# On your server
pip install sensasp-mcp
python3 -m sensasp_mcp.server --transport sse --port 8080

Users add to their config:

{ "mcpServers": { "sensasp": { "url": "https://your-server.com/sse" } } }
