How to Cite SenSASP

If you use SenSASP data in your research, please cite the primary paper and acknowledge the upstream resources below. Proper citation helps sustain this resource.

Primary Citation (APA)

Hao, X., Huang, Y., & Bian, J. (2026). SenSASP: A Unified, Multi-Layer Database of Senescence and SASP Genes. bioRxiv 2026.08.26.747427. https://doi.org/10.64898/2026.08.26.747427

BibTeX

@article{hao2026sensasp, title = {SenSASP: A Unified, Multi-Layer Database of Senescence and SASP Genes}, author = {Hao, Xuan and Huang, Yu and Bian, Jiang}, journal = {bioRxiv}, year = {2026}, doi = {10.64898/2026.08.26.747427}, url = {https://doi.org/10.64898/2026.08.26.747427}, note = {Preprint} }
